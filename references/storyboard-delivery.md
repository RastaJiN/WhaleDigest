# 采用分镜：给下一阶段的是什么

`剧本.md` 确定发生的事、空间事实、对白姓名和逐字原文。`分镜.md` 确定怎么拍；有人工采用稿时保留原文件，编译生成的 `分镜-执行.md` 用于执行。一个项目究竟读哪份执行分镜，以所选批次的 `execution_board` 为准，不依文件名排序，不从旧提示词反推。

| 本镜交接项 | 工作方式 |
| --- | --- |
| 场次、镜号、承接 | 换场标明起始镜号；同场继承上一镜终点。时间省略或有意跳切由分镜交代，不要求前后画面像素相同。 |
| 人、物和空间 | 写谁实际入画、位置与朝向、物件由谁拿、变化在哪一拍发生。机位决定投影左右；性别、谁先说话、参考槽的顺序均不能决定站位。 |
| 动作起点 → 过程 → 终点 | 只有采用的动作才能导出。项目用到动作确认卡时，照读顺序、发起者、节奏、支点、换位和退场选项；纯文戏及空镜无需填这张卡。 |
| 台词与声音 | 标原说话人、画内／画外、逐字台词。反打只换画面，不更换声源、不挂画外演员的人物图。原稿有歧义时先澄清。 |
| 景别和机位 | 记录已选景别和机位，以及叙事所需的变化。近景反应可以只留手或脸，沉默也可以成立；模板不增拍一镜。 |

普通采用稿可用已有中文标题与调度字段；[文戏镜头语言手册](文戏镜头语言手册.md)有可直接采用的例子。[复杂动作确认](storyboard-pose-choice.md)和 [H3 多参考送模格式](official-prompt-assembly-spec.md)分别说明两个下游接口。

**什么能自动判错：** 来源文件变化、明确绑定的镜号或结构化事实被改、未确认的动作进入执行稿、字段或参考不存在。**什么留给人看：** 两句话是否语义等价、沉默是否够长、换角度是否更好、上镜末态和下镜初态在成片里是否真接得住。遇到分歧，改回拥有该事实的剧本或分镜；不要在提示词尾部补一条相反指令。礼貌地提出的导演建议不构成新的生成授权。
