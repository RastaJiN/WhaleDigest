# 通用工程契约：任务源、门禁证据与音频元数据

本记录描述工程接口与验收边界。文本通过、离线负载通过、实际渲染成功和画面质量合格是四种不同结果，不能互相代替。镜头内容与生成质量需要单独验收。

项目用 `.whale_project.json` 的 `active_batch` 指定唯一任务文件。路径必须相对于项目目录；有清单但路径无效时直接失败。没有清单的旧项目兼容读取 `批量任务.json`。门禁、终审、完整性签名、导出器和主运行器共用同一解析器。

Gate 4 按实际任务中的每一个 `prompt` 检查。Markdown 文档拆块检查与任务原文检查使用不同入口；代码围栏不能隐藏任务正文中的错误。六字段格式为 `subject_definitions`、`summary`、`retention_analysis`、`detailed_description`、`overall_soundscape`、`non_diegetic_music`，并要求画面段有独立 `Camera:` 行。真实台词必须在独立 `SPEECH:` 行中有同一行的说话锚点和闭合、非空的语言标签。结构不能由对白中的同名字符串补齐；未闭合的 Markdown 代码块必须报告错误。

门禁证据绑定实际输入：任务选择、任务原文、剧本、分镜、资产与相关校验器版本。Gate 5 另绑定生成的终审报告。输入改变、报告变更或删除、旧记录缺失证据时需要重新验收；历史 PASS 与人工备注不能充当当前证据。实际提交前再次检查当前任务、状态和完整性令牌。签名计算失败时拒绝降级为裸哈希。

任务读取兼容没有 schema 的现有批量文件；显式未知 schema 被拒绝。正式提交前严格检查显式画幅 `aspect`（`16:9` / `9:16` / `1:1`，缺失直接阻断，禁止静默套用默认竖屏）、整数帧数、24 fps 时长、总帧数和 1–9 个有序图像引用。9 个参考图槽位可自由开关并承载任意角色（含 3 人以上群像）、场景或道具，不写死“1=女/2=男/3=场景”；提示词按实际槽位声明 `<Subject N> ↔ <Picture N>`，所有未使用的槽位连接均须断开，缺节点不能生成悬空连接。Gate 1 拒绝空 `00_资产/` 目录；Gate 4、Gate 5 与运行器无条件核验每一镜 `ref_images` 均物理存在于 `00_资产/` 且可解码。用户通过 `--workflow` 或 `.whale_project.json` 的 `workflow` 指定工作流时，运行器按节点 `class_type` 原地回填，严禁私自新建工作流；非肉戏/动画镜头未显式设置 `lora_mystic_strength` 时默认归零 `0.0`。≥5 镜的分镜与批次严禁单一机位、单一景别或静态机位超过 60%。

音频来源独立于后期效果：

| 字段 | 原生音频 |
| --- | --- |
| audio_mode | H3_native_audio |
| audio_reference_required | false |
| ref_audios | [] |

逐镜字段优先于批次字段。显式冲突和错误类型直接报错。旧任务若保留参考音频文件名但没有明确模式，需要迁移，不能默默当成已绑定。元数据可描述 `H3_reference_audio`，但当前运行器没有对应路由实现，明确拒绝实际提交。普通生成音轨输出连接不属于参考音频输入。

完整性令牌长度为 16 个十六进制字符，绑定任务、状态和校验器源文件。随代码分发的固定 HMAC 密钥不构成访问控制边界；收据不会将任务 SHA 的前八位冒充提交令牌。必须在状态保存后使用当前令牌。

生成器、检查器与后处理共用画幅和时长契约。逐镜提示词使用从零开始的局部时间；对白分配完成后重算批次总帧数与总时长。原生音频默认不虚构参考录音。单人镜不要求不存在的听者，空镜不请求人物。纯对白内容不需要无关的动作特写。

目标机自检覆盖中性办公对白、空镜和横竖两种画幅，在隔离目录中完成生成、Gate 1–6 与离线任务校验。CPU 合成样本只证明媒体处理能运行；不会提交模型渲染任务，也不能证明模型权重已加载、显存足够或成片质量达标。

后处理读取当前 `active_batch`，按完整镜号匹配视频。多个候选文件必须明确处理，不能任取一个文件。后处理失败向调用者返回失败；旧输出不能充当本次成功证据。剪映依赖缺失时明确报告，不能自动联网安装。试运行不改写已有字幕或草稿。

工作流模型与账本不一致时明确停止，不静默换模型。随包提供的模型、节点与文档还需与实际部署核对；通过工程检查不能声明全部生产风险已经消除。

运行器按实际 `shot_id` 选择重跑镜头；无匹配、镜号冲突和候选文件名冲突均拒绝执行。服务离线返回失败。超时必须为有限正数，轮询以单调时钟计时。运行器与 Gate 4 使用同一提示词检查器。

断点复用需要当前任务、上游输入、工作流与运行器指纹，以及媒体文件自身 SHA256 一致；缺少或损坏的元数据须重算。检查通过不替代人工画面验收。

后期优先使用精确的规范镜头文件名；同一输出的带音频配对可优先使用，多个不同计数版本必须明确选择。无音轨镜补齐静音轨，母带合成前检查统一尺寸、帧率及任务画幅，拒绝静默丢音或改变画布。
