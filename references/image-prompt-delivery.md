# 图片提示词与参考图：交接给谁、交接什么

图片提示词是**备图说明**，不是已经存在的图片文件。已有采用母版就直接复用，不为满足表格去补做逐镜首帧。此约定不改变宝典的 Ref2VA 路径，也不自动调用生图服务。

每项把四件事说清：**画什么、这一版要固定什么、能控制什么、不能控制什么**。人物母版固定身份和当前造型，不固定站位、台词或每镜表情；地点图固定布局、陈设、光向，不强迫特写复刻广角构图；道具图固定物件形制或已采用状态，不决定角色哪只手拿。状态由剧本和分镜指定。实际文件另记可读的项目内路径及版本。

示例（项目工作稿，不是 H3 正文）：物件“收据”｜状态“未折”｜用途“纸张尺寸和折前轮廓”｜不控制“手别、机位、可见文字”｜实图未提供。此时只能标为待备图；不能造一个文件名，也不能把这行当作已挂图。若剧本需要观众读清某几个字，由分镜注明载体和位置；普通后期字卡可后叠，透视跟踪的手机屏或复杂面板须另行制作，不能冒充普通字卡。

投产时逐镜核实实际 `ref_images` 和工作流输入：槽位代表用途，不代表画面左右；不引入画外人物的母版。缺少必需素材就回到备图或分镜，不默默改成文生视频。图片文件存在与画面内容、身份、服装正确是不同判断，后者要看实际图。
