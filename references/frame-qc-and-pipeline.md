# 交付前的五联抽帧质检与流水线接续

> 引擎门禁全绿 ≠ 成片可用。每一镜落盘后必须肉眼过一遍画面层。

## 一、五联抽帧片与放大校验

```bash
# 等距五帧拼一张横排对比图（0/25/50/75/100%）
ffmpeg -y -i "$F" -vf "select=eq(n\,0)+eq(n\,$N1)+eq(n\,$N2)+eq(n\,$N3)+eq(n\,$LAST),scale=560:-1,tile=5x1" \
       -frames:v 1 -q:v 2 contact_sheet.jpg
```

`N1/N2/N3` 取总帧数的 1/4、1/2、3/4，`LAST` 取 `nb_frames-1`。拼图用于看**动作是否全程在推进**（帧差是否变化）、构图是否稳定、有无字幕烫印。

拼图分辨率会被压到每格 560px，**局部穿模、多余手指、视线的细微偏移在这一级看不出来**。必须再对单帧做 `region` 裁剪放大，取原图坐标（非缩放坐标）：

| 检查项 | 裁剪位置 | 判据 |
|---|---|---|
| 结合部穿模/断根/多出一截 | 双方下腹到臀部交汇处，紧随人物位置取 250×250 框 | 只有一根、全程没入、下腹与臀部贴合无间隙 |
| 多余手/腿 | 全身入画的 `wide`/`mcu` 帧 | 女方 2 手 2 腿、男方 2 手 2 腿，计数逐一确认 |
| 视线是否破第四面墙 | 女/男头部，取 280×160 框 | 脸朝对手，眼不朝镜头 |
| 字幕烫印 | 全画幅 | 任何位置无文字；场景里的小白物件（纸巾盒/便签）不算 |

**裁剪坐标先用全帧图确认人物位置再取框**——同一镜的头部在多帧之间会移动，套用上一帧的框会裁到床板上去，白跑一轮 vision。

## 二、跨镜连续性核验

| 校验 | 方法 |
|---|---|
| 场景是否同一处 | 两次抽帧里比对背景地标（家具、镜框、灯位），不是只比色调 |
| 机位是否同轴 | 男/女方在画面中的左右关系与遮挡层次应与前一镜一致；切换轴线会造成动作矢量断裂 |
| 情绪是否对口 | 逼问镜的眉毛/下颌紧、极乐镜的眼睑松，表情反了等于重拍 |
| 单人镜只有一个人 | `B_solo_female` 镜的男主槽已换成场景图，画面里不该出现男方任何部位 |

## 三、流水线接续（不得空转断火）

单镜跑完到下一镜提交之间不能留空地。用一个轮询等待接续：

```bash
while true; do
  R=$(curl -s -m 8 http://127.0.0.1:8188/queue \
      | python -c "import sys,json;d=json.load(sys.stdin);print(len(d['queue_running'])+len(d['queue_pending']))")
  [ "$R" = "0" ] && break
  sleep 15
done
python submit_batch.py <后续镜号...>
```

把这段整体丢进后台执行（`background=True, notify=True`），不要在前台 `sleep 600`：前台长等待会被新消息打断并转后台，却不触发接续。

## 四、抽帧严重翻车时的处置

质检不过就**停队列**，不要边跑边修。顺序是：定位根因（提示词层 / 机位景别 / 引擎常量）→ 改项目层覆盖 → 只重跑这一镜 → 再抽帧复核。一次性把后续镜也推进去，翻车会以同样原因复制到每一镜。
